# java-lotto-precourse

## 구현 기능 목록

### 로또
- 로또 번호 관리
    - 로또 번호의 숫자 범위는 1~45 이다.
    - 6개의 숫자로 구성된다.

### 당첨 번호
- 당첨 로또 번호를 관리한다.
    - 로또 + 보너스 번호로 구성된다.
- 로또 번호 맞은 개수를 리턴한다.
- 보너스볼 매칭 여부를 리턴한다.

### 당첨 정보
- 당첨 정보를 관리한다.
    - 1등: 6개 번호 일치 / 2,000,000,000원
    - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
    - 3등: 5개 번호 일치 / 1,500,000원
    - 4등: 4개 번호 일치 / 50,000원
    - 5등: 3개 번호 일치 / 5,000원
    - 
### 금액 관리
- 로또 1장의 가격은 1,000 원이다.
- 수익률을 반환한다.

### 로또 발매기
- 로또를 발매한다.
    - 로또 번호의 범위를 참고한다.
    - 로또 개수를 참고한다.
    - 지정된 개수만큼 발행한다.

### 발행된 로또 및 당첨 번호 관리
- 당첨번호와 발행된 로또를 관리한다.
